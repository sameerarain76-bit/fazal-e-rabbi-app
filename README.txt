Fazal e Rabbi Tradders — Master 27 Simple Stock Register

IMPORTANT: Deploy as a NEW GitHub Pages repository or separate /master27/ subfolder first. Do not overwrite the existing live app before testing. Master 27 uses a DIFFERENT localStorage key and does not automatically migrate Master 26 records.

Features: Stock In for many products under one supplier, separate Stock Out with five reasons, separate Expiry Home shortcut, supplier payments and approved return credits, estimated remaining stock at purchase cost, supplier payable, Urdu print-ready ledger and supplier stock statement, JSON export/restore, offline PWA.

PDF creation: Use the browser Print function; on iPhone choose Share/Save to Files from the print preview to create PDF, then send the saved PDF over WhatsApp. No server or WhatsApp API is required.

IMPORTANT: The app is local-only. Keep backups safe. Supplier returns require both a Stock Out and (if supplier has approved credit) an explicit Return Credit adjustment. Stock Out never changes payable directly.
